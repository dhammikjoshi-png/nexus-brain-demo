NEXUS Brain Demo

A tiny Transformer from the NEXUS research project, running entirely in your browser.

What this is, and isn't. It's a ~31,000-parameter research model (2 layers, 32 dimensions, character-level). It is not the NEXUS coding agent and it won't write real programs. Nothing is sent anywhere: the weights load from this site and every token is computed on your device.

1. Generate

The model continues your text one character at a time. Tap a character in the output to see its top 3 candidates.

2. Can it copy a name?

The copy model sees def f(NAME): then return and must repeat NAME. It was trained only on names built from the letters a to t. Try letters it has seen and letters it hasn't.

3. What the experiments found

Summary of Experiments 1 to 4 on this model family. Each result below is a single-model behaviour, not a general claim about large models.

  • Few identifiers means memorising. With about 31 distinct identifiers in training, the model memorises them instead of learning to copy.
  • More variety helps. With 1,000 distinct identifiers it copies about 82% of new strings made from familiar letters.
  • Unseen characters are never copied. It does not copy a character it never saw in training.
  • Copying is positional. It depends on how far the name is from the copy point, not on the function name.
  • More training steps are not a fix. On the code task, longer training did not reliably improve generalisation, and the variation between random seeds was large.

The two models here are single runs (seed 1) from Experiment 4, so section 2 shows one model's behaviour, not an average over seeds.
